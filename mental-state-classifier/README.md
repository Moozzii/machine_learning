# 🧠 EEG Brainwave Mental State Classification

A machine learning project that classifies human mental states from EEG (Electroencephalography) brainwave signals using **Support Vector Machines (SVM)** and **Principal Component Analysis (PCA)**.

The objective of this project was to investigate whether classical machine learning algorithms can accurately distinguish different cognitive states from high-dimensional EEG features while maintaining a clean and reproducible Scikit-Learn pipeline.

---

## 📌 Project Overview

Electroencephalography (EEG) measures the electrical activity generated by neurons in the brain through electrodes placed on the scalp. Because EEG signals change according to cognitive activity, they can be used to recognize different mental states.

This project classifies EEG recordings into three categories:

* 🧘 Relaxed
* 🧠 Concentrating
* 😐 Neutral

The complete workflow includes data preprocessing, dimensionality reduction, hyperparameter optimization, and model evaluation.

---

## 📂 Dataset

**Dataset:** EEG Brainwave Dataset: Mental State

Dataset Characteristics:

* **2,479 samples**
* **989 numerical features**
* **3 target classes**

Target Labels:

| Original Label | Mental State  |
| -------------- | ------------- |
| 0              | Relaxed       |
| 1              | Concentrating |
| 2              | Neutral       |

---

## 🚀 Machine Learning Pipeline

The entire workflow was implemented using a Scikit-Learn Pipeline.

### 1. Feature Scaling

All features were standardized using **StandardScaler** to ensure that every feature contributed equally during optimization.

### 2. Principal Component Analysis (PCA)

The original feature space consisted of **989 dimensions**, making the dataset highly susceptible to redundant information and noise.

PCA was used to reduce the dimensionality to **300 principal components**, preserving the most informative variance while simplifying the feature space.

### 3. Support Vector Machine (SVM)

A Polynomial Kernel SVM was selected to learn nonlinear decision boundaries within the reduced feature space.

Final hyperparameters:

* Kernel: Polynomial
* Degree: 2
* C = 1
* Gamma = 0.01

### 4. Hyperparameter Optimization

GridSearchCV with 5-fold cross-validation was used to systematically search for the best combination of PCA dimensions and SVM hyperparameters.

## 📊 Results

### Classification Report

| Mental State  | Precision | Recall | F1-score |

### Overall Performance

* **Accuracy:** **97%**
* **Macro F1-score:** **0.97**
* **Weighted F1-score:** **0.97**

The final model achieved balanced performance across all three mental states without favoring any individual class.

## 💡 Key Learnings

This project reinforced several important machine learning concepts:

* High-dimensional datasets benefit significantly from dimensionality reduction.
* Proper feature scaling is essential for Support Vector Machines.
* Principal Component Analysis can improve both computational efficiency and predictive performance.
* Hyperparameter tuning using GridSearchCV can substantially improve model performance.
* Balanced evaluation metrics such as Precision, Recall, and F1-score provide a more complete assessment than accuracy alone.
